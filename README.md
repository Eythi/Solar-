Solar
Solar — десктопный музыкальный плеер для Windows, который собирает Яндекс Музыку, SoundCloud и ваши локальные файлы в одну медиатеку, один поиск и одну очередь.

Разработка: QWENTITY TEAM.

Возможности
Один поиск по всем источникам. Одинаковые треки из разных сервисов склеиваются в один (по ISRC, иначе по названию, артисту и длительности).
Общая очередь. Трек из Яндекс Музыки, за ним SoundCloud, потом файл с диска: плеер сам переключается между источниками и пропускает недоступные треки.
Единая коллекция. Лайки из всех сервисов в одном месте, смешанные плейлисты Solar из треков разных источников, список дизлайков.
Волна с выбором настроения, тексты песен, 10-полосный эквалайзер с пресетами.
Аккаунт Solar (вход через Google или по почте). Коллекция и плейлисты синхронизируются между компьютерами.
Оформление: цветовые палитры, свои обои (картинка или видео), стеклянный интерфейс, настройка анимаций.
Работа в трее: музыка играет при закрытом окне, управление из меню трея, автозапуск вместе с Windows.
Обход блокировок для SoundCloud (встроенный zapret) и свой прокси для зарубежных сервисов.
Источники
Источник	Статус
Яндекс Музыка	Работает. Вход по коду на странице Яндекса, без VPN.
SoundCloud	Работает. Поиск без входа, после входа видны лайки и плейлисты. В России открывается через встроенный обход.
Локальные файлы	Работают. Папки с музыкой сканируются автоматически.
Spotify	Скоро. Интеграция готова, но пока закрыта для пользователей.
Установка
Скачайте со страницы релизов один из файлов:

Solar-Setup.exe — установщик (рекомендуется).
Solar.exe — портативная версия без установки.
Windows 10 или 11, x64. При первом запуске войдите в аккаунт Solar, затем подключите источники в «Настройки → Источники музыки».

Сборки пока не подписаны сертификатом, поэтому SmartScreen может показать предупреждение «Неизвестный издатель». Антивирус может ругаться на драйвер WinDivert из zapret: это известное ложное срабатывание, и обход блокировок включается только по вашей кнопке.
